# Campaign patterns

## Problem-to-question map

**When:** translating a broad offering into a focused call path.

For each approved capability, build a PIC row: possible workflow issue, possible business impact and possible root cause. Identify the person likely to understand it, a neutral question, and what would disconfirm the fit. Keep the strongest issue for the opener. Move unverified claims to hypotheses, not sales proof.

**Trade-off:** A sharper hypothesis earns relevance but can be wrong. Design the question so correction is easy.

## Worked example (fictional)

Supplied offering: mapping maintenance-request handoffs before agreeing a pilot. Target: residential property-management operations. Objective: discovery. No price, ROI, integration or existing customer supplied.

- Positioning: help the operations team inspect how requests move between people before deciding whether a pilot is useful.
- Opener: “I’m calling about maintenance-request handoffs. We map the current workflow before proposing a pilot. Is that something your operations team reviews?”
- First question: “How does a maintenance request get from the resident to the person who owns the next action?”
- Conditional follow-up: “Where does context get lost, if anywhere?”
- Next-action question: “Who would need to join a short workflow review if it looked useful?”
- Example fit criterion: organization owns the relevant request-handling workflow; required; a confirmed mismatch can be disqualified.
- Example readiness criterion: appropriate owner willing to review the workflow; use defer or unknown according to the actual timing/context, never invent an imminent purchase.
- Next step: agree a short workflow-discovery conversation if they see a useful purpose.

This example is not proof that any prospect has a broken workflow or will buy.

## Non-sales campaign

**When:** the operator wants interviews or networking.

Use the stated learning or connection goal in the opening. Ask about actual experience instead of promoting a solution. Use relevant permitted outcomes such as permission_to_follow_up or reference_received; no meeting_booked. Do not promise incentives, confidentiality or an eventual partnership unless supplied.

## Scale the ask to actual value

**When:** the nextStep is a generic demo or a large commitment before relevance has been established.

**How:** Use Keenan's Offer − Ask = Value to describe a concrete useful outcome and choose the smallest appropriate action. If an engaged prospect questions that action, Blount's micro-commitment method explains its real benefit before asking again, only while welcome.

**Trade-off:** Smaller asks are not automatically useful. Never rescue a weak offer with invented savings, fake scarcity, free work or a promised deliverable the business has not authorized. Refusal ends the pitch.
